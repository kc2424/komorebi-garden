# 09 — 和名選択ルール（実装仕様）

**結論（先に3行）**

1. **現行の `commonNames[0]` は 72.7% でしか日本語を返さない。** 残り27.3%はローマ字（`Tsukushi`, `Sa zan-ka`, `Dake momi`）か、別種の名前が出ます。
2. **推奨ルール（v3）で 99.1% が日本語、98.8% がカタカナ表記になります。** 元の配列順を保ったまま「カタカナのみの要素」を優先するだけです。並べ替えや最短選択をしてはいけません（標準和名が壊れます）。
3. 日本語名が一切ない **36種（0.9%）は学名にフォールバック**します。ローマ字を出すよりも学名のほうが誠実です。

**状態**: 完了　**検証**: 東アジア4,937種で全数　**作成**: 2026-09-08

---

## 推奨ルール

```
commonNames から表示名を選ぶ：

1. 元の配列順で、最初の「カタカナ・ひらがなのみ」の要素   ← これが標準和名
2. なければ、元の配列順で最初の「日本語のみ（漢字含む）」の要素
3. なければ、元の配列順で最初の「日本語を含む」要素
4. どれも無ければ → 学名を表示（ローマ字は出さない）
```

判定に使う文字範囲：ひらがな・カタカナ `U+3040–U+30FF`、長音符 `ー`、漢字 `U+4E00–U+9FFF`、中黒 `・`

---

## 検証結果（東アジア4,937種、常用名を持つ4,075種が対象）

| ルール | 日本語が出る | カタカナ表記 |
|---|---|---|
| **v0 = `commonNames[0]`（現行実装）** | **2,963（72.7%）** | 2,955（72.5%） |
| v1 = 日本語を含む最初の要素 | 4,039（99.1%） | — |
| **v3 = カタカナ優先・元の順（推奨）** | **4,039（99.1%）** | **4,025（98.8%）** |

### v1 では足りない理由

「日本語を含む最初の要素」だけだと、**属名ラベルや注釈つきの名前**を拾ってしまいます。

| 学名 | commonNames | v1 | **v3** |
|---|---|---|---|
| *Amana erythronioides* | `['Hiro ha-amana', 'アマナ属', 'ヒロハアマナ', ...]` | **`アマナ属`**（属名） | `ヒロハアマナ` |
| *Aster kantoensis* | `['Kawara nogiku', 'カワラ ノギク', 'カワラノギク', '河原野菊']` | **`カワラ ノギク`**（空白入り） | `カワラノギク` |
| *Calycanthus floridus* | `['アメリカロウバイ（広義）', 'クロバナロウバイ']` | **`アメリカロウバイ（広義）`** | `クロバナロウバイ` |

### 「最短を選ぶ」は禁止

短さで選ぶと標準和名が壊れます。**元の配列順を保つこと**が重要です。

| 学名 | 正しい | 最短で選ぶと |
|---|---|---|
| *Abelmoschus manihot* | トロロアオイ | **ネリ**（地方名） |
| *Abies mariesii* | オオシラビソ | **大白檜曽**（漢字表記） |
| *Acer carpinifolium* | チドリノキ | **千鳥の木** |

## それでもPl@ntNetの名前は使わない（重要）

v3 を適用しても、**50種中6種でPl@ntNetの名前は標準和名と違います**。

| 学名 | 標準和名（自前） | v3 適用後のPl@ntNet |
|---|---|---|
| *Trifolium pratense* | アカツメクサ | ムラサキツメクサ |
| *Causonis japonica* | ヤブガラシ | ヤブカラシ |
| *Hemerocallis fulva* | ノカンゾウ | **カンゾ** |
| *Solidago altissima* | セイタカアワダチソウ | **セイタカアキノキリンソウ** |
| *Narcissus tazetta* | ニホンズイセン | スイセン |
| *Spiranthes australis* | ネジバナ | **（常用名なし → 学名）** |

→ **このルールが効くのは「図鑑に未収録の種」のフォールバック表示のときだけ**です。収録50種は自前の和名（[`data/species-shortlist.csv`](data/species-shortlist.csv)）を使ってください。[05 §7](05-recognition-architecture.md) の設計どおりです。
