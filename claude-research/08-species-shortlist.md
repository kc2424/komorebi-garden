# 08 — 対象50種の選定

**結論（先に3行）**

1. **50種を選定し、GBIF照合まで完了。** [`data/species-shortlist.csv`](data/species-shortlist.csv) に `gbifKey` / `genusKey` / `familyKey` / 和名 / 学名 / 科名 / 季節 / 選定理由を格納。**GBIF照合は 50/50 が EXACT**、シノニム解決の必要ゼロ。[02](02-taxonomy-backbone.md) の整数照合設計がそのまま動く形になりました。
2. **「会える頻度」は主観で決めず、GBIFの実測で決めました。** 日本国内の写真つき観察記録（2015–2026、176,997件）を種ごとに集計し、**実際に人が撮っている植物**の順に並べたうえで選んでいます。
3. **冬が構造的に手薄。** 観察ピークが12〜2月の種は110種中**ゼロ**でした。データに従うと図鑑の半分が春になるため、**冬を9種まで意図的に補強**しています（実がなるもの・冬に咲くもの）。

**状態**: 完了　**作成**: 2026-09-08

---

## 1. 選定の基準

| 基準 | 使ったデータ |
|---|---|
| **実際に会える頻度** | GBIF：日本 / 植物界 / 人的観察 / **写真つき** / 2015–2026 の観察件数（176,997件を種別集計） |
| **季節の分散** | GBIF：種ごとの観察月分布。ピーク月と季節性の鋭さ（上位3か月の占有率） |
| **識別の実用性** | 近縁で紛らわしい種は「見分けの練習になるペア」として残し、単なる重複は落とした |
| **体験価値** | 名前の由来・物語が語れるか（自前キュレーション方針＝[05](05-recognition-architecture.md)と整合） |

### 「写真つき観察」に絞った理由

写真なしの記録を含めると、特定の調査データセットが同一件数（4,320件）で大量に並び、順位が歪みました。**写真つきに限定すると「人が見て撮った」記録になり、散歩で出会う頻度の代理指標として機能します。**

---

## 2. 冬の問題（設計上の発見）

上位110種の観察ピーク月の分布：

```
 1月                                      0種
 2月                                      0種
 3月 ██████                               6種
 4月 ███████████████████████████████████ 35種
 5月 ██████████████████████              22種
 6月 █████████                            9種
 7月 █████████                            9種
 8月 ████                                 4種
 9月 ████████                             8種
10月 ███████                              7種
11月 ██████████                          10種
12月                                      0種
```

**12〜2月にピークを持つ種はゼロ。** データのまま選ぶと、冬に散歩しても図鑑が反応しない体験になります。

> ⚠️ ただし注意：**観察ピーク = 開花期ではなく「人が外に出る時期」**です。実際、ブラインドテストで使った1月5日撮影の写真にはホトケノザとオオイヌノフグリが写っていました。冬にも咲いていますが、記録する人が少ないだけです。

**対策**：冬を9種（全体の18%）まで意図的に補強しました。内訳は「赤い実」（ナンテン・マンリョウ・センリョウ・アオキ）と「冬に咲く花」（ツワブキ・ヤツデ・サザンカ・ニホンズイセン・ヒメツルソバ）です。

## 6. この選定の限界

- **地域差**：GBIFの日本全体の集計です。北海道と沖縄では出会う植物が違います。ユーザーの生活圏によっては外れが出ます
- **観察バイアス**：GBIFに記録する人は自然観察に熱心な層です。「珍しいから撮る」バイアスがあり、ありふれすぎる植物（スズメノカタビラ等）は過小評価されている可能性があります
- **識別しやすさは未検証**：Pl@ntNetがこの50種をどれだけ当てられるかは、まだ測っていません（[TODO](TODO.md) A5〜A7と合わせて実測予定）
- **冬の補強は主観**：データに根拠がないため、私の判断で選びました。ユーザーの承認が要ります
