# 07 — 知識層：「特徴」に何を書くか

**結論（先に3行）**

1. **図鑑の劣化コピーを書いてはいけません。** 「萼片5個、雄蕊多数」のような記載は、本物の図鑑に勝てないうえ、散歩の役に立ちません。書くべきは **①いま目の前で見分けられること ②いつどこで会えるか ③名前の物語** の3つです。
2. **1種あたり4項目・約200字**を推奨します。スマホの1画面で読み切れて、歩きながら確認できる量です。項目を固定すると50種を量産でき、抜けも検出できます。
3. **すべての事実に出典を付け、和名と科名は権威データで機械検証します。** [13](13-japanese-name-authority.md) で私のキュレーションから4件の誤りが出た以上、「自分の知識で書く」だけでは品質が保てません。

**状態**: 設計完了・サンプル5種執筆済み　**作成**: 2026-09-08

---

## 1. 何を書かないか

| 書かない | 理由 |
|---|---|
| 形態の学術記載（萼片・雄蕊・子房の数） | 本物の図鑑に勝てない。歩きながら使えない |
| 分布の網羅（「北海道〜九州、朝鮮半島、中国」） | 検索すれば出る。体験に効かない |
| 薬効・食用の断定 | **誤情報が健康被害につながる。** 触れるとしても「食べられません」など安全側のみ |
| 長い文章 | 散歩中に読まれない |

## 2. 何を書くか（4項目・約200字）

| 項目 | 字数 | 役割 |
|---|---|---|
| **一行紹介** | 〜30字 | 図鑑を開いた瞬間の第一印象 |
| **見分けのポイント** | 〜60字 | **いま目の前の株で確認できること**。似た種との違いを1つ |
| **会える季節と場所** | 〜40字 | 次に探しに行ける情報 |
| **名前の物語** | 〜80字 | **体験の核。** 由来・語源・逸話。ここが図鑑との差になる |

### なぜ「名前の物語」が核なのか

散歩アプリの喜びは「名前を知ること」そのものではなく、**「名前の理由を知ること」**です。ヘクソカズラがなぜその名なのか、ホトケノザがなぜ七草の別物なのか。これは分類データベースには載っておらず、**自前で書く価値がある唯一の部分**です。

## 3. 検証の手順（[13](13-japanese-name-authority.md) の教訓）

```
和名   → 維管束植物和名チェックリスト ver.1.10 で機械検証（50/50 一致を確認済み）
科名   → 同上（日本語科名を50/50 取得済み）
学名   → GBIF species/match（50/50 EXACT を確認済み）
生態   → 一次資料を確認し、出典を残す
由来   → 一次資料を確認し、出典を残す。確認できないものは書かない
```

**`data/species-shortlist.csv` の `和名_標準` 列と `和名` 列が一致することを、テストで担保できます。**

### ライセンス

自前執筆なので**ライセンス上の制約はありません**。ただし：

- 特定の図鑑の文章を写さないこと（要約であっても表現を借りない）
- 参照した資料は [`docs/botanical-sources.md`](../docs/botanical-sources.md) の形式で残す（既存の運用と揃える）
- **LLMに下書きさせる場合も、事実は必ず一次資料で確認する**（[05 §Q3-3](05-recognition-architecture.md)）

## 4. サンプル5種

書式の確認用に5種を執筆しました。データは [`data/species-knowledge-sample.csv`](data/species-knowledge-sample.csv)。

### ホトケノザ（シソ科 *Lamium amplexicaule*）

- **一行紹介**：茎を囲む葉を仏さまの蓮座に見立てた、早春の小さな草。
- **見分け**：茎を丸く囲む葉が段になってつく。よく似たヒメオドリコソウは葉が段にならず、上の方が赤紫に色づく。
- **季節と場所**：2〜5月。畑のふち、道ばた、石垣のすきま。暖かければ真冬にも咲く。
- **名前の物語**：春の七草の「ホトケノザ」は**この植物ではありません**。七草の方はキク科のコオニタビラコで、こちらは食べられません。同じ名前の別の植物が2つある、ややこしい草です。

> 出典：和名・科名＝維管束植物和名チェックリスト ver.1.10（「ホトケノザ」がシソ科とキク科の2件で登録されていることを確認）

---

### オオイヌノフグリ（オオバコ科 *Veronica persica*）

- **一行紹介**：早春の地面に散らばる、直径1cmほどの空色の花。
- **見分け**：花びらは4枚で、下の1枚だけが小さく白っぽい。よく似たコイヌノフグリは花がもっと小さく色も淡い。
- **季節と場所**：2〜5月。日当たりのよい道ばた、土手、畑。花は**その日のうちにしぼみます**。
- **名前の物語**：ヨーロッパ生まれで、明治のころ日本に来ました。名は在来種「イヌノフグリ」の実の形から。つまりこの花は「大きい方の、イヌノフグリ」。花の可憐さと名前の落差が有名です。

> 出典：科名（オオバコ科）＝維管束植物和名チェックリスト ver.1.10。旧分類ではゴマノハグサ科

---

### ヘクソカズラ（アカネ科 *Paederia foetida*）

- **一行紹介**：和名の強烈さで知られる、白と紅のつる草。
- **見分け**：花は白く、内側の中心が濃い紅色。葉や茎をちぎると独特の匂いがする（触ったら手を洗ってください）。
- **季節と場所**：7〜9月。フェンス、生垣、河川敷。秋には黄褐色の丸い実が残る。
- **名前の物語**：別名を**ヤイトバナ**といいます。花の中心の赤を、お灸（やいと）の跡に見立てた名前です。同じ花に、いちばん身も蓋もない名前と、いちばん優しい名前の両方がついています。

---

### ヒガンバナ（ヒガンバナ科 *Lycoris radiata*）

- **一行紹介**：秋の彼岸に、葉のない茎の先だけで咲く赤い花。
- **見分け**：花のとき葉がなく、葉のとき花がない。花が終わった後、冬のあいだ細長い葉を広げます。
- **季節と場所**：9月。田のあぜ、土手、墓地。**咲く時期がほぼ1週間**という、季節の目印になる花。
- **名前の物語**：球根に毒があり、ネズミやモグラよけに人が畦や墓地に植えたと言われます。「自然に生えている」ように見えて、多くは人が植えた場所に残ったものです。

> 補足：本調査の実測で、ヒガンバナは観察記録の季節の集中度が全110種中もっとも鋭い種でした（→ [08](08-species-shortlist.md)）

---

### ナンテン（メギ科 *Nandina domestica*）

- **一行紹介**：冬に赤い実をたわわにつける、庭と神社の常連。
- **見分け**：細い葉が枝分かれして並び、実は枝先にまとまってつく。マンリョウは実が葉の下に垂れるので、実の位置で見分けられます。
- **季節と場所**：実は11〜2月。庭、寺社、公園。花は6月ごろの目立たない白。
- **名前の物語**：「ナンテン」が「**難を転じる**」に通じるとして、鬼門に植えたり正月飾りに使われてきました。玄関脇にやたら植わっているのは、この語呂合わせのためです。

## 5. 執筆の進め方（50種）

1. まず**季節ごとに1種ずつ**書いて、書式が体験に合っているかユーザーに確認してもらう（本書の5種がその叩き台）
2. OKが出たら**季節単位でまとめて執筆**（春21 → 夏11 → 秋9 → 冬9）
3. 執筆後、和名・科名の機械検証を通す
4. 「見分けのポイント」で言及した**似た種が図鑑に入っているか**を相互チェック（例：ホトケノザ↔ヒメオドリコソウ、ナンテン↔マンリョウ は両方収録済み）

### 相互参照の候補（すでに50種に両方入っているペア）

| ペア | 見分けの軸 |
|---|---|
| ホトケノザ ↔ ヒメオドリコソウ | 葉が段になるか / 上部が色づくか |
| ナンテン ↔ マンリョウ ↔ センリョウ | 実が枝先か・葉の下か・葉の上か |
| ヤブツバキ ↔ サザンカ | 花ごと落ちるか・花びらが散るか |
| シロツメクサ ↔ ムラサキツメクサ | 花の色と葉の斑 |
| カントウタンポポ ↔ セイヨウタンポポ | 総苞が反り返るか |
| ハルジオン ↔ （ヒメジョオン） | 茎が中空か ※ヒメジョオンは50種未収録 |

→ **ハルジオンの説明で「ヒメジョオンとの違い」に触れるなら、ヒメジョオンも収録すべき**かもしれません。ユーザー判断。
