# 12 — オンデバイス学習データは調達できるか

**結論（先に3行）**

1. **[05](05-recognition-architecture.md) の「Pl@ntNet-300K を土台にできる」は誤りでした。** 実際に種リストを取得して照合したところ、**選定50種のうち収録は8種のみ、同属の種はゼロ**。Pl@ntNet-300K は303属に偏った**MLベンチマーク用データセット**（Sedum 61種、Acacia 39種…）で、日本の植物はほぼ入っていません（*japonica* を含む種は1,081中2件）。
2. **代わりに GBIF が使えます。しかも十分すぎるほど。** 選定50種の写真つき観察記録は世界で **182万枚**、日本だけで **50,825枚**。**48/50 の種が600枚以上**（先行事例 Leafy AI の1種あたり実績値）を確保できます。
3. **ライセンスも問題ありません。** 日本の植物写真の **65.2%が商用利用可**（CC BY 4.0 が43.3%、CC0 が21.9%）。**非商用のCC BY-NCを完全に除外しても、46/50の種が600枚以上**を確保でき、合計 446,874枚が使えます。

**状態**: 完了　**調査日**: 2026-09-08

## 1. Pl@ntNet-300K を検証した結果（[05](05-recognition-architecture.md) の訂正）

[05 §6-3](05-recognition-architecture.md) で「Pl@ntNet-300K（306,146枚 / 1,081種 / CC BY 4.0）が fine-tuning の土台になる。**含有確認は未実施**」と書きました。**確認したところ、使えませんでした。**

種リスト（`plantnet300K_species_id_2_name.json`, 47KB）を取得して照合：

| 項目 | 結果 |
|---|---|
| 収録種数 | 1,081種 / **303属のみ** |
| 選定50種のうち**種として収録** | **8 / 50** |
| 未収録42種のうち**同属の種がある** | **0 / 42** |
| 種小名に *japonica / japonicus / sinensis* を含む種 | **1,081中 2件** |

収録されていた8種：ホトケノザ、ヒメオドリコソウ、ナガミヒナゲシ、シロツメクサ、アカツメクサ、ヘクソカズラ、ヒガンバナ、ナンテン（＝**世界的な帰化植物・園芸種**ばかり）

最も種数の多い属：`Sedum`(61) `Trifolium`(39) `Acacia`(39) `Hypericum`(37) `Ophrys`(29)

→ **Pl@ntNet-300K は「よく似た種を見分けられるか」を測るための難問集**であって、フローラの網羅を目的としたデータセットではありません。日本の散歩植物の学習には使えません。

## 2. GBIF なら足りる

選定50種それぞれについて、GBIF の写真つき観察記録の件数を実測しました。

| 基準（1種あたり） | 種数 |
|---|---|
| **600枚以上**（Leafy AI の実績値） | **48 / 50** |
| 200〜599枚 | 2 / 50（サザンカ 583、ヤマユリ 544） |
| 200枚未満 | **0 / 50** |

| 合計 | 枚数 |
|---|---|
| 世界 | **1,820,327枚** |
| 日本のみ | **50,825枚**（1種あたり平均 約1,000枚） |

上位：アカツメクサ 243,884 / シロツメクサ 232,527 / セイヨウタンポポ 203,217 / ヒメオドリコソウ 176,950 / スギナ 134,295

## 3. ライセンス（ここが本当の制約）

GBIF の写真は記録ごとにライセンスが異なります。日本の植物写真つき記録 524,337件の内訳：

| ライセンス | 件数 | 割合 | 商用利用 |
|---|---|---|---|
| **CC BY 4.0** | 227,252 | 43.3% | **可**（表示義務） |
| CC BY-NC 4.0 | 182,439 | 34.8% | **不可** |
| **CC0 1.0** | 114,646 | 21.9% | **可**（制限なし） |

**商用利用できるのは 65.2%。**

CC BY-NC を完全に除外した場合の、選定50種の学習データ：

| 基準 | 種数 |
|---|---|
| **600枚以上（商用可のみ）** | **46 / 50** |
| 合計 | **446,874枚** |

600枚に届かない4種：**ヤマユリ 173** / サザンカ 379 / カントウタンポポ 425 / カラスウリ 440

→ この4種は Wikimedia Commons や自前撮影で補うか、目標枚数を下げて対応します。

### 注意すべき点

- **CC BY 4.0 は表示義務があります。** 学習に使う場合の帰属表示の扱いは、法域と解釈により見解が分かれます。**商用リリース前に確認が必要**です
- **iNaturalist 由来の記録が多く含まれます。** iNaturalist の利用規約は「データを商用目的の AI/ML 学習に使うこと」を禁じています（[01](01-identification-providers.md)）。GBIF経由で CC0/CC BY のものだけを使う場合でも、**publisher を確認して除外するかどうかは判断が要ります**
- 本調査は**枚数の可用性を測ったもの**で、画像そのものはダウンロードしていません

## 4. Phase 2（オンデバイス化）への結論

[05 §7](05-recognition-architecture.md) の段階的ハイブリッド構想は**維持できます。データ源を Pl@ntNet-300K から GBIF に差し替えるだけ**です。

```
Phase 2 の学習データ調達（修正版）

  GBIF occurrence media（CC0 / CC BY 4.0 に限定）
      ↓  50種 × 600枚以上 = 46/50種で充足、合計 446,874枚から抽出
  + Wikimedia Commons（不足4種の補完）
  + ユーザーの訂正データ（最も価値が高い。Phase 1 で貯める）
      ↓
  MobileNetV3 転移学習（モデル 2〜5MB）
  + Energy score で「図鑑にない」を判定
```

**未検証の課題は変わりません**：open-set（図鑑にない植物の棄却）が最大の難所です（[05 §6-4](05-recognition-architecture.md)）。
