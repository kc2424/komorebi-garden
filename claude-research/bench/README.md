# 自前ベンチ（識別精度の実測用）

カタログスペックの比較では精度は分からないので、**実際に散歩で撮った写真**で測ります。

## 作り方

1. 散歩で 20〜30 枚撮る。条件を意図的に混ぜる：
   - 花のアップ / 株の全体 / 葉だけ / つぼみ
   - 順光 / 逆光 / 曇天 / 雨上がり
   - 単独 / 群生（複数種が写り込む）
2. このフォルダに写真を置く（`001.jpg` `002.jpg` …）
3. `labels.csv` に正解を書く

## labels.csv の書式

```csv
file,和名,学名,器官,撮影条件,備考
001.jpg,ソメイヨシノ,Prunus × yedoensis,flower,順光/アップ,
002.jpg,アジサイ,Hydrangea macrophylla,flower,曇天/株全体,青色
003.jpg,,,leaf,逆光,名前がわからない → 要確認
```

- 正解がわからない写真は 和名・学名を空欄にして「要確認」と書く。あとで調べる
- 園芸品種は分かる範囲で。分からなければ属まで（例: `Tulipa`）

## 測る指標

| 指標 | 意味 |
|------|------|
| top-1 正解率 | 第1候補が正解だった割合 |
| top-5 正解率 | 候補5件のどれかが正解だった割合 |
| **属レベル正解率** | 種は外したが属は合っていた割合（フォールバック設計の根拠） |
| score 分布 | 正解時 / 不正解時のスコアの分布。閾値設計の入力 |
| 誤同定の傾向 | 何と間違えやすいか（近縁種か、無関係か） |

## 注意

- 写真はサイズが大きくなるのでコミットするかは要判断（`.gitignore` 検討）
- 人物・私有地・個人が特定できるものが写り込んでいない写真を使う
