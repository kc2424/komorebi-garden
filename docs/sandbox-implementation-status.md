# 自由な箱庭・試遊版 実装状況

更新: 2026-10-04 JST

## 実装結果

- 初回案内を箱庭中心に変更し、「庭づくりをはじめる」から5×5の草地を直接編集できるようにした。写真記録と設定・引き継ぎは副導線として維持。
- チューリップ（6色）・コスモス・パンジーを、既存の `tulipUnlocked` 値を書き換えず最初から何本でも配置可能にした。既存の観察写真との関連は明示 `observationIds` のみを維持。
- 各タイルを土・草・石の小径へ塗り分け可能にした。草以外の表面では草メッシュを表示せず、石は隣接タイルまで面がつながって見える。
- ベンチ・丸い石・ランタンを外部アセットなしの手続き3Dで追加。花と飾りは単一タイルを排他的に占有し、地面表面とは共存する。
- 「花 / 道・地面 / 飾り」の3カテゴリ、ゴースト仮置き、45度回転、確定・キャンセル、同じ品の連続配置を実装。
- 花と飾りの移動・回転・収納・復帰を実装。土台を外すと載っている花または飾りを収納し、観察と写真リンクは保持する。
- 庭データだけを対象に最大20手の取り消し・やり直しを実装。保存処理を直列化し、保存成功後のみ履歴を進める。観察、写真、認証、同期メタデータは履歴スナップショットに含めない。再読込、ユーザー切替、遠隔/復元状態の適用時は履歴を破棄する。
- 編集中の「保存中… / 保存済み / 保存失敗」を表示し、「眺める」で既存の閲覧カメラと空へ戻れるようにした。
- 表面、配置済み/収納済み飾り、向きを既存v3のIndexedDB・バックアップ・同期シリアライズへ追加。旧v3では欠落値を草/空配列へ正規化する。
- 観察0件の有効なv3が残存v1/v2キーで上書きされる旧移行条件を撤廃。飾り/小径だけの庭も既存データとして再開する。
- 320px向けのコンパクト調整と、44pxを基本にしたモバイル操作領域を追加。
