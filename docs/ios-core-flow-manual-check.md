# iOSコアフローの補助操作チェック

2026-09-10 JST。**iOS Simulatorのコアフローは確認完了**。写真選択→実Pl@ntNet候補→観察保存→直接配置→プロセス再起動→同じ写真・Pl@ntNet API表示の再訪を確認した。保存・配置は本人の補助操作を含む。物理端末や自動引き継ぎの合格とは分ける。

以下は実施した操作と確認範囲。本人が保存・配置を操作し、Astraが結果を目視確認した。再起動は専用Simulatorのアプリをterminate/launchし、花のタップと同じ写真の再訪をCUAで確認した。補助操作の依頼は解消済み。

| 状態 | 操作 | 合格として記録する内容 |
|---|---|---|
| 合格 | 写真選択画面でチューリップ写真をタップ | 「写真の確認」に選んだ写真が表示される。Pl@ntNet APIへの送信案内と「識別を始める」が表示される。 |
| 合格 | 「識別を始める」を1回押し、応答を待つ | 「Pl@ntNet の候補」と候補名が表示される。試験担当が実API応答も確認する。候補の内容を事前に固定せず、写真に合うチューリップ候補を選ぶ。 |
| 合格 | 必要なら「チューリップの色」を選び、「記録を残す」 | 「記録しました」に同じ写真・選んだ名前が表示される。チューリップとして保存できた場合、「この花を庭に植える」が表示される。 |
| 本人操作・最終結果を確認（仮置き文言はAstra未目視） | 「この花を庭に植える」→光っている空き土をタップ | 同じ写真・名前と「この記録の写真と結びつけて植えます」が表示され、選んだ土に仮置きできる。 |
| 本人操作・配置結果を確認 | 「ここに植える」を1回押し、保存を待つ | 選んだ場所に花が1本増える。「完了」が表示されていれば押して庭を眺める状態に戻る。植えた花をタップし、同じ写真と識別方法「Pl@ntNet API」を確認する。 |
| 合格 | アプリのプロセスを終了して再起動し、植えた花をタップ | 同じ位置・色の花が残り、同じ観察写真・名前を再び開ける。再起動はAstraが専用Simulatorのアプリだけを終了・起動して実施できる。アンインストールやデータ消去はしない。 |

試験写真は取り込み済みの画像を使うが、**「サンプルで試す」は押さない**。写真選択から実APIに送信して「Pl@ntNet の候補」が返る経路を検証する。「サンプル写真・固定候補」「手動で選んで保存」「API未設定」「識別に失敗」が出た場合、実識別の合格にはしない。チューリップ候補を取得できなければ、その結果を記録し、無理に別の名前へ変えて直接配置まで合格にしない。

各合格時に画面画像を保存し、実際の表示・API結果・再起動後の状態を試験記録へ追記する。通信エラー、写真が戻らない、同じ写真を開けない等があれば、その画面と操作を残してAstraへ引き継ぐ。この手順だけでは、物理iPhoneのカメラ・権限操作、自動引き継ぎ、ストア配布は検証済みにならない。
