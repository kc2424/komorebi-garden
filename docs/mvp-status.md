1. **和名**: `commonNames[0]` → v3（カタカナ優先・配列順保持）。Tulipa は学名 ID を保持し表示は「チューリップ」+ 簡潔な特徴文。
2. **属境界**: `isTulipaScientificName` を先頭属名トークンのみに限定（部分文字列 false positive 排除）。
3. **サンプル写真**: `sample-tulip` が kikyo（桔梗）を指していた問題を修正。Wikimedia 赤チューリップ実写真に差し替え、クレジット記録。
4. **不明保存**: エラー/未設定時は「不明・判別できない」が先頭・既定。API 成功時も末尾に拒否オプション。`identificationSource` は API 候補選択時のみ `plantnet`。
5. **前処理**: 登録・識別パイプラインを長辺 1280px / JPEG q0.9 に更新。

## 外部ブロッカー

### Astra独立ブラウザ確認（研究取り込み後）

390×844の隔離ブラウザで、サンプルボタンではなくファイル入力から実チューリップ写真を送信。Pl@ntNetの候補からTulipa gesnerianaを選び赤色で保存し、2本を配置。再読込後に観察の `identificationSource=plantnet`、`isSample=false`、写真保持、赤色、植栽2本を確認。別途アジサイ写真を送信し、非チューリップ候補から「不明・判別できない」を選んで保存。観察のみ追加され、手動確認扱いで植栽数は増えないことを確認した。

今回の実API呼び出しはCursorのスモーク2回＋Astraの画面検証2回。画像は出典付きの公開写真で、ユーザーが散歩で撮った写真や実機カメラの検証ではない。テスト19件成功、最終スコア表記修正後のbuild成功はCursor実行結果を確認した。回転・土編集・しまう・移動は前回の独立ブラウザ検証済みで、今回の修正範囲外。

APIキー待ちは解消。仮モデルで実写真識別から庭への一周が通る段階。最終モデルの受領・組込みと実端末でのユーザー体験確認は未完了。

## コアフロー（Astra ブラウザ確認用）

1. サンプル「チューリップ（体験用）」→ 赤チューリップ写真が表示されること → 確認・色選択 → 観察保存 → 庭で植える
2. 自分の写真 or API → 候補拒否で「不明・判別できない」保存できること
3. 土を足す/外す → 花がしまわれる → 再植付
4. 再読込で庭・観察が残る
